# Archived Scripts

This subdirectory contains scripts that are no longer actively used but kept for reference.

## Purpose

Scripts in this directory are:
- Superseded by newer implementations
- One-time migration or fix scripts that have been run
- Experimental scripts that didn't make it into the main workflow
- Historical scripts for reference

## Best Practices

When moving a script here, add a comment in the script or this README explaining:
1. What the script did
2. Why it's no longer used
3. Date archived
